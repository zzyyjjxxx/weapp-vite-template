# 用地需求填报 UI 规范

用地需求流程面向手机端，固定采用五步向导：基本信息、用地需求、投资项目、融资及联系人、信息确认与提交。每步显示进度，第一至四步提供明确的上一步、暂存、下一步动作；第五步提供编辑入口、真实性承诺和验证码提交。

## 组件边界

- 页面与组件使用 Wevu Vue SFC，运行时 API 从 `wevu` 导入。
- 表单、按钮、对话框等优先使用 TDesign MiniProgram；结构可用小程序原生 `view/text/scroll-view`。
- 允许使用 `src/styles/tailwind.css` 和 `weapp-tailwindcss` 的构建期工具类；不存在浏览器 Tailwind 配置或运行时。
- 通用 `PageShell`、`AppLoading`、`AppEmpty`、`AppError` 不依赖业务领域。
- 可交互节点保留稳定 `data-testid`，供小程序 Automator E2E 使用。

## 视觉与反馈

沿用 `src/styles/tokens.scss` 中的颜色、间距和字号，不新增第二套 UI 库。必填提示紧邻字段；保存、发送验证码和提交期间禁用重复操作；领域错误显示中文可行动信息。会清空已有值的切换必须先显示 TDesign Dialog，经用户确认后再清空。

## 关键显隐规则

- `is_deploy=是`：显示多选调配区域并在正式提交时必填；“宁波市”与具体区域互斥。
- `is_specialuse=是`：只控制单选的 `deploy_landtype` 显示和正式提交必填。
- 期望层高、期望承重始终显示且选填，切换 `is_specialuse` 不得清空它们。
- `is_financing` 新建默认“没有”；只有“有”时显示融资金额和期望融资时间并在正式提交时必填。
- 切换产业赛道会清空发展方向并加载新赛道对应选项。

## 字段文案

固定资产投资额、预计营收、预计税收、预计研发费用使用“万元”；项目单位能耗增加值使用“万元/吨标煤”。这些项目指标均为必填。项目建设内容使用多行文本，按 `text` 语义不设置 UI 字符上限。国民行业展示 `行业名称（行业编码）`，提交只保存编码。

任何界面变更均需通过 `pnpm stylelint`、构建和有条件的微信开发者工具运行验收；静态构建不能替代页面交互或截图证据。
